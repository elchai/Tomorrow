# TOMORROW — רשת ניבוי פשיעה 🚓

נוצר ב-2026-05-20

## תיאור
מערכת לניבוי פשיעה ("Tomorrow") בסגנון מוקד שיטור טקטי / משחק מחשב SWAT.
בהשראת פרויקט 443 — מפה אינטראקטיבית, שכבות איום וחיזוי — אך **ללא** חלק התכנון המבצעי.
המערכת מציגה תחזית פשיעה ל-24 השעות הקרובות לפי אזורים, סוגי עבירה ורמת סיכון,
ומאפשרת **הזנקת ניידות משטרה** ממוקדות לתחנה הקרובה ביעד (אנימציית רכב על המפה,
בהשראת רעיון הזנקת המטוסים מ-FireOps).

## פיצ'רים (v0.1)
- 🗺️ מפה כהה טקטית (Leaflet + CartoDB Dark) עם מפת חום (heatmap) ומוקדי חיזוי פועמים
- 🔮 מנוע ניבוי מבוסס-כללים — ציון סיכון שקוף לפי סוג עבירה, שעה, סופ״ש והיסטוריית אזור
- 🕒 ציר זמן 24 שעות — גרירה לצפייה בתחזית לפי שעה
- 🚓 הזנקת ניידות — בחירת מוקד → אנימציית רכב מהתחנה הקרובה ליעד + "טבעת אבטחה"
- 🛡️ סיור מונע מוגבר ("רוויה") על מוקדי סיכון גבוה
- 🏢 בורר תחנות/מרחבים (מרחב ירקון / איילון — תל אביב)
- 📡 יומן מבצעי + רמת איום מצרפית (DEFCON)
- 💾 שמירת מצב מקומית (localStorage)

## הרצה
אין שלב build. שרת סטטי כלשהו:
```powershell
npx http-server -p 8777
# ואז http://localhost:8777
```
או פשוט לפתוח את `index.html` בדפדפן.

## מבנה הקוד
| קובץ | תפקיד |
|------|--------|
| `index.html` | מעטפת — boot, HUD, סיידברים, מפה, ציר זמן |
| `config.js` | קבועים — סוגי עבירה, רמות סיכון, תחנות, סוגי יחידות, כרטיסי תגובה |
| `app.js` | State גלובלי, persistence, בורר תחנות, שעון, toast, יומן, boot |
| `prediction.js` | מנוע הניבוי — יצירת מוקדים + חישוב סיכון (החלף את `getForecast()` במודל אמיתי) |
| `map.js` | מפת Leaflet, heatmap, טבעות סיכון, סמני תחנות/מוקדים, רדאר |
| `dispatch.js` | הזנקת ניידות + אנימציית AVL (מעובד מ-FireOps) |
| `style.css` | ערכת נושא SWAT כהה |
